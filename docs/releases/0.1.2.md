# Rebased Background Studio v0.1.2

本版把 0.1.2-beta.1 与 0.1.2-beta.2 转为正式版。

## 新增与修复

- 支持多项目窗口独立背景和随机／顺序轮播。图片充足时，宿主为不同窗口避开重复图片；新开窗口不重置其他窗口的背景和计时。
- 修复 Islands 主题下背景仅出现在外围、Log 提交列表等主体仍为黑色的问题，并兼容动态创建的表格单元格。
- 去除 Islands 区块额外的深色边缘填充，修复内边距残留粗黑边；保留原有细分界线、圆角和选中状态，不新增阴影遮罩。
- 普通面板背景合成前使用统一窗口底色，避免相同图片透明度在不同区块产生明显暗色块。不修改全局主题颜色；暂停／恢复时撤销绘制调整。
- 按项目隔离文字对比度增强；完善窗口关闭、重新打开、多进程短暂断线及暂停状态处理。
- 加强桥接协议的嵌套 JSON、消息大小和窗口归属校验。

## 性能

- 环境检测不再每秒做两次全量进程快照并重新解析 `product-info.json`（约 23 ms CPU/s，430 个进程时）：改为增量跟踪新进程、每 10 秒一次全量快照，并在安装信息文件变化前复用解析结果。
- 图像处理依赖按 opt-level 3 构建，渲染约快 25%，输出逐字节一致。

## 升级须知

- **更新后需要正常重启 Rebased**，才能加载新版桥接插件。请先保存当前工作；旧桥接会明确提示重启，不会静默降级。
- 多窗口独立轮播需要支持 `perWindowMedia` 的 Background Studio 宿主（0.3.6 或更高）。旧宿主仍使用单媒体模式；欢迎页不计为项目窗口。
- 保留现有媒体库、轮播与显示配置。

## 验证

- Rust 测试 45 项通过；Java 桥接协议、文字隔离、Islands 背景与边框、统一底色回归（6 组）通过。
- 在本机 Rebased 1.1.19 的两个项目窗口实测：同图前后对照、主体覆盖、细分界线、暂停恢复及不同图片独立轮播。
- 经预发布渠道数日实际使用，未发现问题。
